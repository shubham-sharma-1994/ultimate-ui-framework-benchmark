# Pulse App - Quasar

This is the Quasar framework implementation of the Pulse benchmark app.

## Project Setup

```bash
cd apps/quasar
pnpm install
```

### Run for Web

```bash
pnpm dev
```

### Build for Web

```bash
pnpm build
```

### Build for Android

```bash
npx cap add android
npx cap sync android
npx cap open android # Or build with gradle
```
