# Pulse App - Qt Implementation

This is the Qt 6 (QML + C++) implementation of the Pulse App benchmark.

## Setup
Ensure you have Qt 6.4 or later installed (e.g. via `aqtinstall` or the Qt Maintenance Tool).

## Build and Run (Desktop)
```bash
mkdir build && cd build
cmake ..
make -j
./PulseApp
```
